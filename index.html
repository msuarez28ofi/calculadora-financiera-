Conceptos de Ingenieria Economica

Bienvenido a la Calculadora Financiera. Utiliza el botón de menú lateral (☰) en la esquina superior izquierda para seleccionar el tipo de análisis matemático financiero que deseas realizar.

Nomenclatura Estándar Aplicada:

F: Valor Futuro (Monto Total)
P: Valor Presente (Capital inicial)
I: Interés ganado en dinero
i: Tasa de interés (decimal)
n: Número de períodos (Tiempo)

Interés Simple

Los intereses se generan únicamente sobre el capital inicial durante cada período.

Fórmulas Base:

• Interés (I): I = P · i · n
• Valor Futuro (F): F = P(1 + i · n)

Despejes desde Interés (I):

• Capital: P = I / (i · n)
• Tasa: i = I / (P · n)
• Tiempo: n = I / (P · i)

Despejes desde Valor Futuro (F):

• Capital: P = F / (1 + i · n)
• Tasa: i = ((F / P) - 1) / n
• Tiempo: n = ((F / P) - 1) / i

Interés Compuesto

Los intereses se capitalizan, calculándose sobre el capital inicial más los intereses acumulados anteriores.

Fórmulas Base:

• Valor Futuro (F): F = P(1 + i)n
• Interés Acum. (I): I = P[(1 + i)n - 1]

Despejes fundamentales:

• Capital (Presente): P = F / (1 + i)n
• Tasa por período: i = n√(F/P) - 1
• Tiempo (períodos): n = ln(F/P) / ln(1 + i)
